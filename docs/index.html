About

More than 20 years of experience in database architecture, software development, and, more recently, AI-assisted engineering, with a particular focus on PostgreSQL.

Builds open-source developer tools that make working with PostgreSQL simpler — from an instant JSON-RPC API layer to schema exporters, dump splitters, and a native SQL formatter, mostly written in Go and Python.

Writes about databases, software, and the occasional detour on the blog Port 80, and shares quick PostgreSQL tips on Telegram — online as heptau.
