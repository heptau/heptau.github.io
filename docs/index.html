CLI Tools
pgArachne
Instant PostgreSQL API gateway — turn your database into a secure JSON-RPC API with zero boilerplate. Native MCP support for AI clients (Claude, Cursor), real-time SSE notifications, and database-native auth with RLS.
pgDBML
Export PostgreSQL schemas to DBML format for diagramming. Connect directly to a database or parse pg_dump output. Generates clean DBML ready for dbdiagram.io, Mermaid, or other visualization tools.
pgAtropos
Split PostgreSQL dumps into individual schema files for Git versioning. Creates separate files per object — tables, functions, indexes — ready for version control and code review.
pgProcrustes
PostgreSQL SQL formatter in Go. Fast, flexible formatter driven by the native PostgreSQL parser. Supports keyword casing, data type formatting, layout, and clause breaking.
TypoLima
Conservative typographic fixer for HTML, PHP, Hugo, and text files. Fixes quotes, dashes, non-breaking spaces, ellipses for 33+ languages. Only touches text content — never code, tags, or template variables.
GUI Apps
OmniDB
Open-source database management tool — lightweight, fast, and collaborative. Web-based GUI for PostgreSQL with schema browser, query editor, data explorer, and multi-user support.
pgAdmin III
GUI administration tool for PostgreSQL — missing macOS binaries. Available via pre-compiled app or Homebrew installation.
SQLFluff UI
Cross-platform desktop app for configuring SQLFluff visually. Set dialect, indentation, and layout rules — see formatted SQL live. Built with Python and PySide6, no command-line knowledge required.
Web Apps
Compound Interest Calculator
Online compound interest calculator with history tracking. Calculate investment growth from initial deposit, contributions, rate, and time. PWA installable, works offline, includes calculation history.
Odorik Dash
Dashboard for monitoring Odorik VoIP credit balance and usage. Real-time credit tracking, call history overview, and service status for Odorik.cz customers.
Odorik
Web app for managing Odorik VoIP services. Quick contacts dialer, call history with recordings, SMS composer with character counter, and account settings.
QR Generator
QR code generator for text, URLs, Wi-Fi, geolocation, email, phone, SMS, SEPA payments, and Czech QR payments. Customizable colors and error correction with PNG download.
